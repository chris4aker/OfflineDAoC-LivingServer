- **Every CI gate fails on failure** (#618; owner, 2026-11-25: "make sure each CI or checker is properly written and
  designed"). The `launcher` check is a real gate (it had `continue-on-error`, so a failing launcher test left the run
  green). The server job's feature-test and passport-lock re-runs (`|| true`) became gates read from the suite's own
  results, and a missing results file, simulated transcript or bench file now fails the step. The chat audit's verdicts
  moved to a `report: chat audit` job that is not required. Every entry of `.github/ci-excluded-tests.txt` carries a
  reason and an issue (#619); six classes whose synthetic tests had never run in CI came off the list (about 105 more
  tests now gate). The bot-voice, command-reference and reachability checkers got tests that plant a defect.
  `docs/CI.md` lists each job, what it gates and which only report. CI and tools only; no game change.
