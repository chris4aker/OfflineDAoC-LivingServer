version: 1.2.3
section: Setup and launcher
---
- **The name is now DAoC - Living Server** (#641; owner, 2026-11-25). Setup, its Start menu folder and its shortcuts
  read "DAoC - Living Server". New installs go to `C:\Games\LivingServer` by default. Existing installs stay where they
  are and keep updating.
- **Faster base-game download** (#641). Setup's own downloader fetches the base game's parts in parallel over up to six
  connections, with byte ranges inside the large parts. A cut connection or a stopped Setup continues where it stopped.
  Every part is still checked against its SHA-256 and refused on a mismatch. Setup shows the combined speed, and its
  log records the MB/s. If the downloader stops, the original download script fetches what is missing, as before
  (`FastDownloadTests`). **Tests only.**
- **The launcher reads DAoC - Living Server** (#641). This covers its window title, its header, the Herald and Economy
  pages, and Host for Friends and Join a Friend. New firewall rules from Host for Friends are named "DAoC - Living
  Server friends ...". Rules an earlier build made are still found and removed. The server's default name and the
  welcome messages name the product too. A world whose welcome messages are untouched moves once, and one with its own
  text keeps it (`UT_Rebrand641`).
- **The launcher is DAoCLivingServer.exe, and the package is DAoC-LivingServer-<version>.zip** (#641). Your game folder
  keeps an OfflineDAoC.exe that opens the same launcher, so the game's start file, your old shortcuts and older
  launchers' updates still work. Every release from 1.2.3 also carries the package under its old name,
  OfflineDAoC-LivingServer-<version>.zip, so 1.2.0-1.2.2 launchers still find the update. ROLLBACK.cmd puts the
  earlier launcher back. Setup is DAoC-LivingServer-Setup-<version>.exe (`PackageRename641Tests`, the installer script
  tests).
- **About and credits** (#641). The launcher has an **ABOUT** button. It shows the product, its GPL v3 license and every
  project and person whose work is in it. It also shows the "not affiliated with Electronic Arts or Broadsword" notice. The same text is
  `CREDITS.md` in the repository (`AboutCredits641Tests`).
