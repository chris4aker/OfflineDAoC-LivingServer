- **Test builds** (#637; owner, 2026-11-25: "pre release sounds like the right way to go. I want Ryan and FarmVibes to
  access as well"). Release candidates are published as GitHub pre-releases (`v1.2.3-rc.1`): `publish-release` has a
  `prerelease` input, and the release is never Latest. The launcher's new **Offer test builds (pre-releases)** setting
  (off by default) also offers the newest test build, shown as a TEST BUILD and checked against GitHub's SHA-256
  digest like every update. **Install into a new test folder** makes a fresh install beside the current one
  (`<folder>-test`) with a clean world and installs the test build there; the current install's world, account, logs
  and backups are never copied. Tests only.
