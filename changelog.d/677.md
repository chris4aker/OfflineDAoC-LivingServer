- **Setup's downloader rides out a dropped connection, and leaves no half-finished copies behind** (#677). After a
  timed-out connection, the next try could fail inside Windows' own web code ("Cannot access a disposed object"), and
  that stopped Setup's fast downloader after one error. It now tries that range again, like any other network error. When
  the fast downloader does give up and the original download script fetches the base game, Setup now removes its own
  unfinished copies of the parts (about 4.8 GB) once each part is in place and checked against its SHA-256. A part that
  isn't in place yet keeps its copy, so the next run still continues it. The installer's end-to-end test now checks that
  no unfinished download files are left after a new install (`FastDownloadTests`). **Tests only.**
