- **Bot healers stack heals over time the way the server does** (#567 A3).
  A heal over time or a regeneration is now held back only by an effect the server would make it clash
  with, so a Skald's Song of Rest no longer stops a Shaman keeping regeneration up, and a healer doesn't cast a heal over
  time over the one a groupmate is casting at the same target.
